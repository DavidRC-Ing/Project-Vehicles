# 🚗 Project-Vehicles
**Análisis de Datos de Anuncios de Venta de Vehículos**

🌐 **URL del Proyecto:** [Project-Vehicles en Render](https://project-vehicles-fift.onrender.com)

![Vehicles Dashboard](https://via.placeholder.com/900x400.png?text=Project+Vehicles+Dashboard)

---

## 📋 Descripción del Proyecto
**Project-Vehicles** es una plataforma web desarrollada para el **análisis de anuncios de venta de vehículos**.  
El sistema ofrece al usuario acceso a información detallada sobre los datos recopilados, complementada con gráficos interactivos que facilitan la interpretación y análisis de las tendencias en el mercado automotriz.  

La plataforma incluye una **interfaz intuitiva** que permite aplicar filtros personalizados para explorar datos específicos, analizar patrones de oferta y demanda, y detectar puntos estratégicos para la toma de decisiones.

---

## ✨ Características Principales
- 📊 **Visualización de Datos:** gráficos dinámicos y explicativos sobre las ventas de vehículos.  
- 🔍 **Filtros Personalizados:** segmentación de datos por marca, modelo, precio, kilometraje, etc.  
- 🌐 **Interfaz Web Intuitiva:** acceso fácil y navegación fluida para el usuario.  
- 🚘 **Análisis de Tendencias:** identificación de patrones clave en el mercado automotriz.  
- ⚡ **Aplicación en Render:** accesible desde cualquier dispositivo con conexión a Internet.  

---

## 🛠️ Stack Tecnológico
`Python` · `Pandas` · `Plotly` · `Matplotlib` · `Seaborn` · `Flask` · `HTML/CSS` · `JavaScript` · `Render`

## 🎯 Beneficios y Hallazgos
- 👥 Comprensión más clara de la **distribución de vehículos** en venta.  
- 📈 Identificación de **tendencias del mercado automotriz** según variables clave.  
- 🔎 Uso de **filtros dinámicos** que facilitan focalizar en información de alto valor.  
- 🚀 Base sólida para **estrategias de compra/venta** fundamentadas en datos.
